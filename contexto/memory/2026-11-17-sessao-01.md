## Decisões
- **10 imagens em ordem cronológica**, escolhidas e revisadas pelo usuário (usuário).
- **Rota `/api/carousel` na API**, e o site lê dela com `buscarComCache(config.prefixoCache + 'carrossel', config.apiUrl + '/carousel')`. O `config.json` fica só com o link (usuário escolheu entre "rota" e "config.json"). Isso muda a US02: o link continua centralizado e as imagens vêm da API.
- **Imagens baixadas para a API, sem hotlink na Wiki**, porque o CDN da Wiki recusa acesso sem o `Referer` dela (Claude).
- **Slide 4 com `episode: null`**, porque a Wiki marca a foto do superlaboratório como "unknown episode" (Claude).
- **Na API o Claude pode commitar; no front, não** (usuário). O push da API (deploy na Vercel) só com confirmação.

## Problemas encontrados
- **Commit da API bloqueado:** o `deny` de `git commit` do `.claude/settings.json` deste projeto vale para a sessão inteira, mesmo com `cd` para a API. O Claude não contornou. Para commitar na API, abrir o Claude na pasta `API_BB` ou ajustar a regra.
- O CDN da Wiki entrega `.webp` por padrão; com `?format=original`, vem PNG/JPEG.
