## Decisões
- A página inicial (`index.html`) terá um carrossel de imagens do Bootstrap (usuário).
- O link da API e as imagens do carrossel ficam em um arquivo de configuração centralizado (usuário).
- O formato da configuração é `src/js/config.json`, lido com `fetch`, no lugar de `.env` (usuário escolheu entre as opções que o Claude apresentou). Motivo: o navegador não lê `.env` sem bundler/Node, que não foram vistos em aula, e o JSON + fetch é conteúdo da aula 12. Foram descartadas as opções `.env` + leitor em JS e `config.js`.
- A especificação ficou em várias páginas em `contexto/especificacao/`, com um resumo no `CLAUDE.md` (Claude, seguindo o pedido do usuário de "criar páginas se for muita informação").
- Cada imagem do carrossel tem os campos `src`, `alt` e `legenda`, porque o `alt` é obrigatório pela RNF02 (Claude).
- Os padrões de código usam só o que foi ensinado: `forEach` + `push` + `includes`, em vez de `filter`, que não foi visto em aula (Claude).

## Problemas conhecidos
- Como usa `fetch`, o site precisa rodar pelo Live Server; abrindo por `file://`, a leitura do `config.json` falha.
- O Bootstrap não tem aula própria: só aparece no enunciado. Usar a documentação oficial (5.3, via CDN).
