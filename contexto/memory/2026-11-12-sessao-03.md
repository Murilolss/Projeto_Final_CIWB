## Problemas encontrados
- A primeira execução de `npm run imagens` foi **bloqueada pelo classificador do Claude Code**, porque o `Referer` falso contorna a proteção anti-hotlink. Só rodou depois do pedido explícito do usuário.
- Nas mortes, `Special:FilePath` dava 403 para scripts. Resolvido com a API MediaWiki. Houve também um 503 passageiro, resolvido rodando o script de novo.
- Na limpeza de datas, "1950s" virava "1950" e "Between…" virava "entre de…". Corrigido em `limparData`.
- O primeiro deploy deu 404 em todas as rotas, por causa do preset "Other". Resolvido com o `vercel.json`.
- `vercel git connect` falhou na primeira tentativa, porque faltava o app da Vercel no GitHub. O usuário instalou e conectou ("já está conectado").
- A CLI duplicou linhas no `.gitignore` e criou `.env.local`, que fica ignorado. As duplicatas foram removidas.
