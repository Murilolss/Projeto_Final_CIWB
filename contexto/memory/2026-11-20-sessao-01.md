## Decisões
- **Autoplay de 5 s** com pausa no hover (usuário, entre "autoplay" e "sem autoplay").
- **Legenda = nome + "Episódio 5x07"** (usuário).
- **Cache só dos dados** (JSON com o link de cada foto) em `ciwb_carrossel`, consultado antes da API. Os `.jpg` **não** vão para o localStorage e ficam no cache HTTP do navegador. O usuário pediu que o cache fosse consultado antes da API e confirmou que não precisa guardar as fotos. Guardá-las exigiria base64 + `FileReader` (não vistos em aula) e ~1,8 MB do limite.
- **Altura do carrossel:** foi reduzida para 380/220px, mas voltou para **480/260px** a pedido do usuário.
- **Slide 4 = 3x06 "Pôr do Sol"** (usuário). A correção foi feita na API, e não no front. Por um momento o front mostrou "Temporada 3" (com `split('/')` no link `season`), mas isso foi retirado quando o episódio foi informado, para manter o código simples (Claude).

## Problemas encontrados
- O `data-bs-ride="carousel"` não funciona em carrossel criado pelo JS depois do carregamento. A solução foi iniciar com `bootstrap.Carousel.getOrCreateInstance` (o mesmo padrão do Modal).
- O `resize_window` do Chrome não encolheu a janela maximizada. Os 375px foram medidos num iframe.
- O commit da API continua bloqueado para o Claude pelo `deny` de `git commit` deste projeto. O usuário commitou.
- Quem já tinha visitado a página antes do deploy da API tem o slide 4 com `null` no cache. Para ver o 3x06: `localStorage.removeItem('ciwb_carrossel')` e recarregar.
