## Decisões
- **O Claude não faz commit nem push.** Só passa a mensagem, e o usuário commita manualmente (usuário). Vale só para este projeto: no repositório da API (`Arnaldo/API_BB`) não precisa (usuário).
- **Branches:** `main` = produção, `dev` = integração, uma `bb/<integrante>` por integrante. Por enquanto só a do usuário, `bb/murilo` (usuário; o nome `murilo` veio do nome no Git, e o usuário não contestou).
- **Quadro:** colunas e regras de dependência iguais às do quadro de INOO; prazos trocados pela entrega única de 08/12; placar de requisitos no lugar da sincronização com o GitHub (Claude).
- **Integrantes editáveis no próprio quadro**, porque os outros membros do grupo ainda não foram informados (Claude).
- **Sem revisor automático nos PRs** (no quadro de INOO havia uma regra fixa por pessoa). O campo "Revisor" é livre, porque o grupo ainda não está definido (Claude).
- **T-26 (página de temporadas) sem requisitos ligados**, para o placar não travar caso a página não entre (Claude).
- **Ressalvas do `frontend-design`:** animações que dê para explicar ao professor, código simples, só HTML/CSS/JavaScript (usuário). Animações de rolagem são permitidas (usuário). Os detalhes (o que é permitido ou proibido, `IntersectionObserver` como única exceção de JS para rolagem) são do Claude.
- **Cópia local do plugin em vez do `claude plugin install ...@claude-plugins-official`**: o plugin oficial instala fora do repositório e não aceita ressalvas; a cópia vai no Git para o grupo todo (Claude). Não instalar também a versão oficial, para não duplicar a skill.
- **Caminho relativo no `settings.json`** (`./.claude/plugins`), para funcionar nos clones dos colegas (Claude).

## Problemas encontrados
- O Git não cria branch sem commit: com o repositório vazio, só deu para renomear `master` → `main`. A `dev` e a `bb/murilo` foram criadas depois do primeiro commit do usuário.
- `claude plugin marketplace add` grava o caminho **absoluto** da pasta no `.claude/settings.json`. Foi trocado à mão pelo relativo. Nesta máquina continua funcionando, porque o registro do usuário em `~/.claude/plugins/known_marketplaces.json` guarda o absoluto. **Não foi testado num clone novo:** se lá não funcionar, o README do plugin explica como reinstalar (sem commitar o caminho absoluto).
